# Python Utilities (`python/utils/`)

## Purpose & Scope
This directory is reserved for lightweight Python helper utilities that may assist the AI engine during development, evaluation, and data handling.

## Potential Future Responsibilities
* Format converters (e.g., converting clinical metadata tables to CSV/JSON).
* Path resolution and file I/O helpers.
* Test runners and diagnostic scripts.
* Note: No heavy ML packages or third-party AI frameworks should be added here.
